# PhysScope project page

[Project website](https://shenxianasi.github.io/PhysScope/) for *PhysScope: Agentic Multimodal Physics Reasoning with Grounded Visual Memory*. [Paper](https://arxiv.org/abs/2611.23010) · [Research code](https://github.com/HCPLab-SYSU/PhysScope)

The page is plain HTML, CSS, and JavaScript. Open `index.html` directly for a local preview or run `python -m http.server` from this directory. GitHub Pages publishes the root of the `main` branch.

The interactive pulley schematic is adapted from Figure 1. The static figures and experimental results come from version 2 of the paper.
