# PhysScope project page

[Project website](https://hcplab-sysu.github.io/PhysScope/) for *PhysScope: Agentic Multimodal Physics Reasoning with Grounded Visual Memory*. [Paper](https://arxiv.org/abs/2611.23010) · [Research code](https://github.com/HCPLab-SYSU/PhysScope) · [PhysAlign benchmark](https://physalign-lab.github.io/)

The page is plain HTML, CSS, and JavaScript. Open `index.html` directly for a local preview or run `python -m http.server` from this directory. The publishing source for the HCP project site is the root of the `gh-pages` branch.

The interactive pulley schematic is adapted from Figure 1. The static figures and experimental results come from version 2 of the paper.
